Lab E: New Period + Cash Flow

Initialize 2025 P1 & P2, load trial balances, configure movement classifications, run cash flow

Period ManagementLab60 min
📋 Lab Overview

This lab walks through the complete month-end and new-year initialization workflow for 2025. You will open two new periods, enter exchange rates (including account-level rate overrides), roll opening balances from 2024 P12, load new trial balance data, run consolidation, validate results, and configure the cash flow calculation.

Periods: 2025 P1 and 2025 P2  |  Source files: "Initialize New Period" folder  |  Entities with new data: London, Paris

E1
Update Global Variables and Open New Periods
5 min
Objective Set the system's current period to 2025 P1 and open both 2025 P1 and 2025 P2 for data loading.
  1. 1 Navigate to Configure → Global Variables.
  2. 2 Update Current Year to 2025 and Current Period to P1. Save.
  3. 3 Navigate to Configure → Open Periods.
  4. 4 Add a new row for 2025 P1 (click + or duplicate an existing row and update the year/period values).
  5. 5 Add a second row for 2025 P2. Both periods should now appear in the table.
✅ You're done when...
The Open Periods table shows rows for 2025 P1 and 2025 P2. Global Variables shows Current Year = 2025, Current Period = P1. Report date defaults now show 2025 P1 in journal date fields.
E2
Enter Exchange Rates for 2025 P1 and P2
10 min
Objective Enter standard FX rates for the new periods, then configure account-level rate overrides for London entities.
  1. 1 Navigate to Maintain → Foreign Exchange Global Rates.
  2. 2 Enter End Rate and Average Rate for EUR and GBP for periods 2025 P1 and 2025 P2. Use the rates in the "Initialize New Period" folder file. Remember: decimal separator is a period (.) not a comma.
  3. 3 For account-level rate overrides: navigate to Maintain → Override Rates.
  4. 4 If the + (Add) button is not visible: go to Security settings → set Consolidation → All. Return to Override Rates. The + button should now appear.
  5. 5 Add override rate entries for London entity, accounts 3000 and 3100 (GBP→USD):
    • Entity: London
    • Date: (fill in the period date)
    • Scenario: Actuals
    • Account: 3000 → Rate: 0.75
    • Account: 3100 → Rate: 0.74
    • Leave Cost Center, Audit, Product fields empty
  6. 6 Save the override rates. Note: the Date field is mandatory — leaving it blank will prevent processing.
✅ You're done when...
Standard FX rates appear in the Foreign Exchange Global Rates form for 2025 P1 and P2. Two override rate entries appear for London entity (accounts 3000 and 3100) with rates 0.75 and 0.74 respectively.
E3
Run Copy Opening and Load Trial Balances
10 min
Objective Roll 2024 P12 closing balances forward as 2025 P1 opening balances, then load 2025 P1 trial balance data for London and Paris.
  1. 1 Navigate to Consolidation → Processes.
  2. 2 Run Copy Opening for period 2025 P1. This copies 2024 P12 closing balances as 2025 P1 opening balances.
  3. 3 Wait for Copy Opening to complete successfully before proceeding.
  4. 4 Load 2025 P1 trial balance data for London using the file from the "Initialize New Period" exercise folder. Use the same import definition as prior data loads.
  5. 5 Load 2025 P1 trial balance data for Paris entity.
  6. 6 Run Run All for period 2025 P1.
✅ You're done when...
Copy Opening completes without errors. London and Paris 2025 P1 trial balance data is visible in the system. Run All completes for 2025 P1.
E4
Run Validation Reports
5 min
Objective Verify opening balance integrity and movement validity using the two standard validation reports.
  1. 1 Navigate to the Reporting module. Find and run the Validations Open Period report for 2025 P1.
  2. 2 Review results: green checkmarks indicate opening balances are correctly rolled forward. Red X's indicate discrepancies that must be investigated before close.
  3. 3 Run the Movement Validations report for 2025 P1.
  4. 4 Review results: some red X's on a first run are expected if balance sheet continuity data has not yet been entered. Document which checks are failing and why.
✅ You're done when...
You have reviewed both validation reports. The Validations Open Period report shows green checkmarks for entities with correctly rolled-forward opening balances. Movement Validations may show some red X's — this is expected on first run and indicates where balance sheet continuity data is needed.
E5
Configure Movement Classifications and Cash Flow Rules
20 min
Objective Create movement classifications, assign them to balance sheet accounts, configure cash flow calculation rules, run the calculation, and view the cash flow statement.
  1. 1 Navigate to Maintain → General Setup → Movement Classifications. Click + to create a new classification.
  2. 2 Create classification "Current BS": set Opening = false, Closing = false, Intercompany = false, Total Cash = true, Non-Cash = true. Save.
  3. 3 Create classification "GPE" (for PP&E with depreciation/amortization): configure flags as appropriate for this account type. Save.
  4. 4 Navigate to the Accounts Dimension. Single-click account 17117 (PP&E account). In the Attributes section, assign the GPE movement classification.
  5. 5 Assign the Current BS classification to appropriate current balance sheet accounts (receivables, payables, etc.).
  6. 6 Check whether cash flow accounts already exist in the Accounts Dimension (from the Company ABC workbook activity). If yes, skip the import step and go to step 7. If no, import the cash flow account hierarchy file using Append mode.
  7. 7 Navigate to cash flow calculation rules. For each cash flow statement row, create a header record (target cash flow account, model, Active = true) and detail records (target movement, target audit, operator +/–, source GL accounts, source movement member).
  8. 8 Run the Cash Flow Calculation process from the Processes menu.
  9. 9 Navigate to the Reporting module and open the Cash Flow Statement report for 2025 P1. Review the populated lines by operating, investing, and financing activity.
✅ You're done when...
Movement classifications exist and are assigned to at least two balance sheet accounts. Cash flow calculation rules are configured for the key cash flow statement lines. The Cash Flow Statement report shows populated values for 2025 P1. You can drill from a cash flow line to the underlying GL account and movement dimension member.
ℹ Post-Workshop: Balance Sheet Continuity Input

Entering actual movement detail values in the Balance Sheet Continuity Schedule requires the Fluence Excel add-in, which was not installed on all workshop machines. If you are on a PC with the add-in installed (or using a Windows VM), you can access the continuity schedule and enter movement values (yellow editable fields in Excel). Your workshop tenant remains accessible for approximately 5 weeks after the workshop — use this time to explore this feature with real data.

⚠️ Common Issues in This Lab
  • Override Rates + button not visible: Go to Security → set Consolidation = All, then return to Override Rates
  • Rate entry not processing: Ensure the Date field is filled in — leaving it blank prevents the rate from being saved
  • Copy Opening fails: Verify the target period is listed in Configure Open Periods before running Copy Opening
  • Validation report red X's: First run red X's on Movement Validations are expected — they indicate missing balance sheet continuity entries, not system errors
  • Cash flow accounts disappeared after import: You used Overwrite instead of Append — reload GL accounts from the source file using Append mode
  • Cash flow statement shows zeros: Verify Copy Opening was run and that source movement members in the calculation rules match the members populated by the balance sheet continuity data
