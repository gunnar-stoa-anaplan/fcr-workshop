Lab D: Consolidation Engine

Currency conversion, journals, ARAP elimination, and consolidation method validation

Consolidation EngineLab60 min
📋 Lab Overview

This lab brings together currency conversion, journals, and consolidation rules into one end-to-end exercise. You will configure GBP as a second reporting currency, post a reclassification journal, set up an ARAP intercompany elimination, validate consolidation methods (NCI/equity/proportional), and verify results in the consolidated reports.

Period: 2024 P12  |  Reference file: 2024-2025 conversionrates.xls (exercise folder)  |  Validation entity: E13 Berlin

D1
Configure GBP as a Reporting Currency
15 min
Objective Add GBP as a second reporting currency, enable triangulation, enter exchange rates for 2024 P12, and run conversion.
  1. 1 Navigate to Maintain → Currency Dimension. Find the GBP member.
  2. 2 Set the following attributes on GBP: reporting = true, triangulate = true, rate_operator = Divide.
  3. 3 Verify that all_currency and no_currency members do NOT have rate operator attributes. Remove them if present.
  4. 4 Navigate to Maintain → Foreign Exchange Global Rates.
  5. 5 Verify USD base currency rates are set to 1 for both End Rate and Average Rate.
  6. 6 Using the provided 2024-2025 conversionrates.xls file, enter rates for 2024 P12 for EUR and GBP. Remember: the web form uses period (.) not comma (,) as the decimal separator.
  7. 7 Navigate to Consolidation → Processes and run Run All for period 2024 P12.
  8. 8 Open Consolidated Financials by Entity. Filter to E13 Berlin. Drag the Currency dimension to columns.
✅ You're done when...
E13 Berlin shows values in all three currencies (EUR, USD, GBP) side-by-side. The Cash account should show approximately EUR ~190 and USD ~224. GBP values are visible in a third column.
D2
Enable Journals and Post a Reclassification Entry
15 min
Objective Activate journal permissions, create a journal configuration, and post a reclassification journal entry from Cost of Sales to Accounts Payable.
  1. 1 Confirm with the facilitator that the Journals feature flag is enabled on your tenant. (Pre-enabled for this workshop via the Excel settings file.)
  2. 2 Go to Security → Role Authorizations (3rd tab). Enable ALL journal permissions for your role. Click Save.
  3. 3 Verify the Journals module now appears in the left navigation. If not, refresh the browser.
  4. 4 Navigate to Configure → General Configuration → Journal Configuration. Click +.
  5. 5 Configure the journal: select your consolidation model; set Data View = Fixed value (Value); set Audit default query = Manual Journal; Audit default input = Reclassification; Date default input = Global Current Period.
  6. 6 Set header dimensions: Entity, Intercompany, Audit, Period, Scenario. Set detail dimensions: Account, Movement, Amount. Save the configuration.
  7. 7 Go to Journals module. Create a new journal entry with the following lines:
  8. 8 Debit line: Account = Cost of Sales, Intercompany = 3RD, Movement = Closing, Amount = positive value.
  9. 9 Credit line: Account = Accounts Payable, Intercompany = 3RD, Movement = Increase, Amount = negative value (same absolute value). Save and post.
✅ You're done when...
The journal is posted successfully. In Consolidated Financials by Audit, drill into the Contribution rollup and find the Reclass (Reclassification) audit column — your journal amounts appear against Cost of Sales and Accounts Payable.
D3
Configure and Run ARAP Intercompany Elimination
20 min
Objective Set up the AR/AP intercompany elimination rule, configure intercompany matching and auto-booking, and validate the elimination in the consolidated reports.
  1. 1 In the Account Dimension, verify the ARAP offset account exists under the Accounts Payable hierarchy. Tag it with the IC matching tag (#ICMATCHAR). Confirm the auto-booking account also exists (separate from the offset account).
  2. 2 Go to Maintain → Consolidation Rules. Create a new rule named "ARAP Elimination". Select your consolidation model. Set Active = true.
  3. 3 In the detail rows: add a row for the AR side (source = AR accounts via tag; target = ARAP_OFFSET; set appropriate repartition rule). Add a row for the AP side with sign reversed.
  4. 4 Assign the consolidation rule to both AR and AP accounts via the Account Dimension → Consolidation attribute.
  5. 5 Navigate to Maintain → Intercompany Matching. Add a header row. Add detail rows for AP (sign = –, type = Payable) and AR (sign = +).
  6. 6 In the Booking section: add two auto-booking lines (debit and credit). Set the intercompany dimension to No Intercompany. Add the auto-booking account to the matching header with a minus sign. Click Save and Process.
  7. 7 Run Run All (or Run Consolidation) for 2024 P12.
  8. 8 Open Consolidated Financials by Audit → look for the IC Elimination audit column. Open the IC Matching Report.
✅ You're done when...
The IC Elimination audit column shows elimination entries in the Consolidated Financials by Audit report. The IC Matching report shows matched amounts between entities. Note: a known version issue may affect the IC Matching report display — your facilitator will show what the correct output should look like.
D4
Validate NCI, Equity, and Proportional Method Rules
10 min
Objective Activate and validate the out-of-the-box consolidation rules for NCI, equity method, and proportional method. Verify results in the consolidated-by-audit report.
  1. 1 Open Maintain → Managed Ownership. Verify that the ownership percentages match the expected values for your workshop model entities.
  2. 2 Go to Maintain → Consolidation Rules. Find the pre-configured NCI, equity method, and proportional method rules. Set Active = true on each.
  3. 3 Review the NCI rule detail rows. Verify that NCI accounts (Retained Earnings Minority, Current Earnings Minority, Capital Minority, Dividends Minority, CTA Minority) are linked via the consolidation attribute in the Account dimension.
  4. 4 Run Run All for 2024 P12.
  5. 5 Open the Consolidated-by-Audit report. Look for the Shares audit column (equity/financial investment elimination entries) and NCI audit column.
✅ You're done when...
The Consolidated-by-Audit report shows entries in the Shares audit column for equity eliminations and in the NCI-related audit columns for minority interest postings. Ownership percentages match the managed ownership table.
⚠️ Common Issues in This Lab
  • Conversion results missing: Check P_conversion attribute on all accounts; verify GBP triangulate = true in currency dimension
  • Wrong decimal separator: Web form uses period (.) not comma (,) for FX rates
  • Journals module not visible: Save Security permissions first, then refresh browser
  • IC Elimination not posting: Verify consolidation rule Active = true; verify tag names match exactly
  • Balance sheet imbalance after ARAP: The auto-booking account may need to be added to the matching header with a minus sign — check the intercompany matching configuration
