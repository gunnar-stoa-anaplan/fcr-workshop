Ownership & Consolidation Methods

Entity hierarchy, direct ownership, the ultimate rate calculator, and consolidation method assignment

Data Model & Configuration25 min
📖 Tell The Ownership Model How entity hierarchy attributes, direct ownership percentages, and consolidation methods work together to drive consolidation calculations.
👁 Show Direct Ownership Table Demo A short walkthrough demonstrates entering ownership percentages, date-bounding ownership changes, and running the Ultimate Rate Calculator.
✅ Do Lab B: Ownership Setup Configure consolidation methods, enter all direct ownership percentages, run the Ultimate Rate Calculator, and verify method assignment.

Entity Dimension — Key Attributes

Beyond the basic hierarchy structure, each entity member in the Entity dimension has attributes that drive ownership and consolidation behaviour:

Table 08: Entity Dimension Attributes
Attribute Values Purpose
Currency e.g., USD, EUR, GBP The functional/local currency of this entity. Used as the base for currency translation.
Entity Type Group or Entity Group type: this member appears in the Group dimension (enables subconsolidation). Entity type: this member is a legal entity that does NOT populate the Group dimension.
Holding Company True / False Marks the holding company within a subgroup. At least one entity per subgroup must have this flag set to true — required for consolidation calculations to run correctly.
Source GL Audit Member Audit dimension member Links this entity's loaded trial balance data to a specific Source GL audit member. Useful in multi-source environments (one audit member per ERP system).

The Total Group Tag — Critical Requirement

⚠️ Missing Total Group Tag — Silent Failure

The Total Group tag must exist on the top-level parent member in three dimensions: Entity, Company, and Group.

If this tag is missing from any of these dimensions, the Direct Ownership table will not show all required dimensions (Scenario, Entity, Intercompany) in its left-hand panel. Default reports and input forms also rely on this tag to function correctly.

Symptom: You open Direct Ownership and the left panel only shows one dimension instead of three. Fix: Go back to the Entity, Company, or Group dimension and add the Total Group tag to the top-level hierarchy member in whichever dimension is missing it.

Direct Ownership Table

The Direct Ownership table is where you enter the legal ownership relationships between parent and child entities. Navigate to Maintain → Ownership → Direct Ownership.

Each row in the table represents one ownership relationship:

Table 09: Direct Ownership Table
Column Description
Parent Entity The holding entity that owns the child
Child Entity The entity being owned
Ownership % Direct ownership percentage (0–100)
Start Date Period from which this ownership percentage applies (e.g., 2020 P01)
End Date Last period this ownership percentage applies (leave blank if still current)

Handling Ownership Changes Over Time

When ownership percentages change (e.g., a divestiture), you do NOT overwrite the existing row. Instead, you add a new row and use start/end dates to bound each period of ownership:

📋 Example: Brussels Entity — 10% Divestiture
Table 10: Handling Ownership Changes Over Time
ParentChild%StartEnd
EuropeBrussels100%2020 P012021 P05
EuropeBrussels90%2021 P06(blank — still current)

The first row covers the period when Europe owned Brussels at 100%. After the divestiture in May 2021, a new row is added from June 2021 at 90%. The system uses the date-bounded rows to apply the correct percentage in each period's consolidation run.

Ultimate Rate Calculator

Direct Ownership holds the legal ownership relationships. The Ultimate Rate Calculator reads all direct ownership entries and calculates the effective group-level ownership percentage, taking into account chains of ownership (e.g., Parent owns 80% of Sub A, Sub A owns 90% of Sub B → Parent's ultimate rate in Sub B = 72%).

To run it: navigate to Maintain → Ownership → Ultimate Rate Calculator → click Run.

After running, the Managed Ownership table is auto-populated with the calculated consolidation method for each entity:

  • Entities where ultimate ownership >50% → assigned Global method
  • Entities where ultimate ownership = 50% → assigned Proportional method
  • Entities where ultimate ownership is 20–50% → assigned Equity method
💡 Why This Step is Essential

Consolidation rules depend on the Managed Ownership table to know which method applies to each entity. If you skip running the Ultimate Rate Calculator, or run it before Direct Ownership is complete, consolidation calculations will produce incorrect results. Always run the Ultimate Rate Calculator after all Direct Ownership entries are complete.

Consolidation Methods

Consolidation methods are configured in Maintain → Consolidation → Methods. The percentage ranges for each method are configurable to match the customer's accounting standards.

Table 11: Consolidation Methods
Method Default Ownership Range Treatment
Global >50% to ≤100% Full consolidation — 100% of the subsidiary's trial balance is included in the consolidated financials. NCI (non-controlling interest) entries are posted to eliminate the minority portion of equity.
Proportional Exactly 50% 50% of the subsidiary's trial balance is included. The remaining 50% is backed out via consolidation rules. No NCI — both parties own equal shares.
Equity >20% to <50% The entire trial balance of the associate is eliminated. Only the group's share of net income is retained in the consolidated output (shown as "Income from Associates").
ℹ️ Additional Custom Methods

The three standard methods cover most consolidation scenarios, but additional custom methods can be added to the Methods table if needed. Custom method logic requires collaboration with Anaplan — contact your Anaplan Professional Services team if a customer's structure falls outside these three options.
