Lab B: Ownership Setup

Configure consolidation methods, enter ownership percentages, and run the ultimate rate calculator

Data Model & Configuration30 min
🎯 Lab Objective

By the end of this lab, every entity in the workshop model will have ownership percentages configured, consolidation methods set up, and the Managed Ownership table auto-populated by the Ultimate Rate Calculator.

1
Configure Consolidation Methods
5 min
Objective Set the ownership percentage ranges that determine which consolidation method is applied to each entity.
  1. 1 Navigate to Maintain → Consolidation → Methods
  2. 2 Locate the Global method → set range: >50% to ≤100%
  3. 3 Locate the Proportional method → set range: = 50%
  4. 4 Locate the Equity method → set range: >20% to <50%
  5. 5 Click Save
✅ You're done when...
All three consolidation methods are configured with the correct percentage ranges and the page saves without errors.
2
Verify Entity Dimension — Holding Flag & Total Group Tag
5 min
Objective Confirm that the Entity dimension has the Holding Company flag and Total Group tag correctly configured — both are prerequisites for Direct Ownership to work correctly.
  1. 1 Navigate to Models module → Dimensions tab → Entity
  2. 2 Review the entity hierarchy — verify that each subgroup has at least one entity with Entity Type = Holding
  3. 3 Find the top-level hierarchy member (the root/parent of the entire entity structure) → verify it has the tag Total Group
  4. 4 Navigate to the Company dimension → find the top-level member → verify it also has the Total Group tag
  5. 5 Navigate to the Group dimension → find the top-level member → verify Total Group tag is present here too
  6. 6 If any tag is missing, add it now and click Save → Process
✅ You're done when...
The Holding Company flag is confirmed on at least one entity per subgroup, and the Total Group tag exists on the top-level member in all three dimensions (Entity, Company, Group).
3
Enter Direct Ownership
15 min
Objective Enter all parent-child ownership percentages for the workshop model, using the Entities fill tab from the requirements workbook.
  1. 1 Navigate to Maintain → Ownership → Direct Ownership
  2. 2 Confirm the left panel shows Scenario, Entity, and Intercompany dimensions
    If only one dimension shows: stop — return to Mini-Lab 2 and fix the missing Total Group tag before continuing.
  3. 3 Using the Entities fill tab from the requirements workbook as your reference, enter a row for each parent-child ownership relationship:
    • Parent entity, child entity, ownership percentage
    • Start date (use the earliest period in scope, e.g., 2020 P01)
    • End date (leave blank unless there is an ownership change)
  4. 4 For any entity where ownership changed during the period covered by the model: add a second row for the same parent-child pair with a new start date and updated percentage; set an end date on the original row
  5. 5 Review your entries — check that all leaf entities have at least one parent with an ownership percentage
  6. 6 Click Save
✅ You're done when...
All entities from the requirements workbook have ownership entries in the Direct Ownership table. Any ownership changes are represented as date-bounded rows (not overwrites). Save completes without errors.
4
Run the Ultimate Rate Calculator
5 min
Objective Calculate effective group-level ownership rates and verify that consolidation methods are automatically assigned to each entity.
  1. 1 Navigate to Maintain → Ownership → Ultimate Rate Calculator
  2. 2 Click Run
  3. 3 Navigate to Maintain → Ownership → Managed Ownership
  4. 4 Review the results — each entity should show:
    • Its calculated effective ownership percentage
    • An assigned consolidation method (Global, Proportional, or Equity)
  5. 5 Verify that the assigned methods match what you'd expect based on the ownership percentages
✅ You're done when...
The Managed Ownership table is populated with effective ownership percentages and consolidation methods are correctly assigned (Global / Proportional / Equity) based on the percentage ranges you configured in Mini-Lab 1.

Lab B Completion Checklist

  • Consolidation methods configured: Global >50%, Proportional =50%, Equity >20–<50%
  • Holding Company flag confirmed on at least one entity per subgroup
  • Total Group tag confirmed in Entity, Company, and Group dimensions
  • Direct Ownership table fully populated from requirements workbook
  • Date-bounded rows used for any ownership changes (not overwrites)
  • Ultimate Rate Calculator run successfully
  • Managed Ownership shows correct methods for all entities
🔧 Common Issues & Fixes
Left panel in Direct Ownership shows only one dimension
The Total Group tag is missing from one of the three dimensions (Entity, Company, or Group). Navigate to the dimension with the missing tag, find the top-level hierarchy member, add Total Group to its tags, and Save → Process before returning to Direct Ownership.
Ultimate Rate Calculator runs but shows no results in Managed Ownership
Most likely cause: Direct Ownership entries were not saved before clicking Run. Go back to Direct Ownership, confirm entries are there, Save, then re-run the Ultimate Rate Calculator.
Method is not assigned correctly to an entity
Check the percentage ranges in the Methods configuration (Mini-Lab 1). The ranges must correctly cover the percentage in your Direct Ownership data. Also verify that the Direct Ownership percentage for that entity is correct.
Entity doesn't appear in Direct Ownership
The entity may not be a leaf-level member, or the entity dimension may not have been processed after the last import. Run Save → Process on the Entity dimension and try again.
