What Is Narrative Reporting?

Narrative Reporting (also called Disclosure Management) is a separate Anaplan product — it is not included in the standard FCR license. It is an add-on designed for the last mile of financial close: the creation, review, and sign-off of board packs, annual reports, press releases, and statutory filings.

Key positioning facts:

  • Built on Microsoft Word and PowerPoint — not Google tools, which is seen as a major advantage with finance teams already using Microsoft 365
  • Direct competitor to Workiva
  • Can connect to FCR, Anaplan planning models, TM1, Power BI, and HR systems — not limited to FCR data
  • Anaplan does not typically provide implementation services for Narrative Reporting — partners and customers deploy it themselves
  • Deployment timeline: as little as 5–10 days using Inverse Design on existing documents
💡 Goldman Sachs Reference Case

Goldman Sachs is replacing Workiva with Anaplan Narrative Reporting for approximately 10,000 reports. Key reasons cited: preference for Microsoft tools (Word/PowerPoint over web-native), and per-user pricing vs. per-report pricing which makes large-scale rollout more economical.

Inverse Design — The Key Differentiator

Unlike traditional reporting tools where you define the layout first and then populate it with data, Narrative Reporting uses Inverse Design:

📄
Traditional Approach
Define template layout → Map data to sections → Publish. Changing the layout requires rework of all data mappings.
🔄
Inverse Design (Narrative Reporting)
Upload your existing Word or PowerPoint document → system automatically creates section structure → connect data sources to each section. Up and running in 5–10 days.

The design is driven by the data model and document structure, not a blank-canvas layout. This dramatically reduces time-to-value, especially for organizations that already have established report templates.

FCR + Narrative Reporting Integration

FCR provides the consolidated numbers. Narrative Reporting pulls those numbers into the report without manual copy-paste:

  1. FCR runs the consolidation and produces finalized consolidated financials
  2. An Anaplan Excel data source file (stored in the cloud) connects to FCR data via named ranges
  3. The Word/PowerPoint report document links to those named ranges in the data source file
  4. When FCR numbers update (e.g., a late journal entry), the data source file refreshes and flags affected sections in the report — the report owner decides when to accept the refresh

This eliminates the most error-prone step in reporting: manually copying numbers from a consolidation system into a Word document. Changes in FCR flow through automatically, with full control over when the published document reflects them.

📌 Partner Guidance: Which to Recommend?
  • Use Narrative Reporting for board/management packs, internal reporting, and organizations already on the Anaplan platform
  • Recommend Workiva if the customer has SEC filing requirements, mandatory XBRL/ESEF tagging, or is a public company with complex regulatory obligations
  • Some large customers use both — Narrative Reporting for management reporting, Workiva for statutory/regulatory submissions

Licensing Note

⚠️ Separate SKU Required

Narrative Reporting requires a separate license SKU — it is not included in the standard FCR or FPC license. Always confirm with your Anaplan Account Executive before scoping Narrative Reporting into an implementation proposal. Scoping it without confirming licensing can create commercial surprises late in a deal.

Verify whether a separate Narrative Reporting tenant needs to be provisioned — it is provisioned differently from the FCR consolidation tenant and may require additional lead time.
