Lab A: Data Model Setup

Build the foundation — dimensions, accounts, currencies

Data Model & Configuration45 min
🎯 Lab Objective

By the end of this lab, you will have a fully configured FCR data model ready for data loading. You will create custom dimensions, import entity and account hierarchies, configure currencies, and link everything into the Consolidation model.

✅ Prerequisites
  • Your FCR tenant credentials are confirmed and you can log in
  • Workshop exercise files are downloaded from the shared folder (Data Model Basics Solution folder)
  • You have reviewed the Data Model theory page
1
Create Custom Dimensions
15 min
Objective Add Cost Center and Product as custom dimensions, populate them, and link them into the Consolidation model.
  1. 1 Navigate to Models module → Dimensions tab
  2. 2 Click the blue + button → set Type = Other → enter Name: Cost Center → Save
  3. 3 Click the blue + button again → Type = Other → Name: Product → Save
  4. 4 Select the Cost Center dimension → click the cloud+up (import) icon → choose Append mode → upload the Cost Center elements file from your exercise folder
  5. 5 Repeat step 4 for the Product dimension
  6. 6 For Cost Center: set Default Reporting Member to the Total element (parent of the hierarchy) → set Default Input Member to any leaf-level element
  7. 7 Repeat step 6 for Product
  8. 8 Navigate to Models module → Model tab → single-click the Consolidation model → click the + button in the dimensions panel → select Cost Center → click Add
  9. 9 Repeat step 8 to add the Product dimension to the model
  10. 10 Click Save (💾) → then Process (⚙️⚙️)
✅ You're done when...
Processing completes with no errors, and both Cost Center and Product appear in the Consolidation model's dimension list.
2
Import Entity and Account Dimensions
15 min
Objective Load the entity hierarchy and account dimension from the requirements workbook files, then configure the three workshop currencies.
  1. 1 In the Dimensions tab, click on the Entity dimension
  2. 2 Click the cloud+up (import) icon → select Replace mode → upload the Entity dimension file from your exercise folder
  3. 3 Verify the hierarchy loaded correctly — you should see subgroups and leaf-level entities in the hierarchy view
  4. 4 Click on the Account dimension → import icon → Replace mode → upload the Account dimension file
  5. 5 Navigate to the Currencies section (within the same Dimensions tab or Currency sub-menu)
  6. 6 Locate the Canadian Dollar entry → rename it to GBP
  7. 7 Verify the three currencies now present are: USD, EUR, GBP
  8. 8 After each import: click Save → then Process
✅ You're done when...
The entity hierarchy displays correctly (subgroups visible with leaf entities beneath them), the account dimension is loaded, and the currency list shows exactly three currencies: USD, EUR, and GBP.
3
Verify Model Configuration
5 min
Objective Confirm the Consolidation model is correctly configured and a default report opens without errors.
  1. 1 Navigate to Models module → Model tab
  2. 2 Click the Consolidation model to open its configuration
  3. 3 Confirm that Cost Center and Product appear in the model's dimension list
  4. 4 Navigate to the Reports module (or Consolidated Financials) → open any default report
  5. 5 Confirm the report opens without any error messages about missing dimension members or configuration
✅ You're done when...
The default report opens cleanly without errors. (No data yet — that's expected. Just no errors.)

Lab A Completion Checklist

  • Custom dimension Cost Center created (Type: Other)
  • Custom dimension Product created (Type: Other)
  • Default Reporting Member set for Cost Center and Product
  • Default Input Member set for Cost Center and Product
  • Both dimensions added to the Consolidation model
  • Entity dimension imported successfully
  • Account dimension imported successfully
  • Currencies configured: USD, EUR, GBP
  • Save → Process completed with no errors
  • Default report opens without errors
🔧 Common Issues & Fixes
Save → Process completes but shows an error
Most likely cause: Default Reporting Member or Default Input Member not set on one of your custom dimensions. Go back to the Dimensions tab, select the dimension, and set both defaults.
Custom dimension doesn't appear in reports
You created the dimension but forgot to add it to the Consolidation model. Navigate to Models → Model tab → click Consolidation model → click + → add the dimension.
Import fails with a column error
Column names in the file must exactly match the staging table column names — including case. Check the file headers against what FCR expects. VARCHAR columns for dimension text values, FLOAT for numeric amounts.
Entity hierarchy looks flat (no parent-child nesting)
Check the isLeaf column in the import file — it must correctly indicate parent vs. leaf elements. Also verify the Parent column is populated for non-root elements.
